# CouchSubs development builds

For this project's future approved development builds, run the relevant local tests, commit the build changes, and push them to the current CouchSubs feature branch on `origin`. Check the matching GitHub Actions run and provide its link, the application version, and the build number. Do not publish a public release or merge to the default branch unless requested.

Keep the Windows and webOS build numbers in sync when the Windows workflow packages both. Follow any newer release instructions from the user.
